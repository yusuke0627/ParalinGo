# MyGO評価ログ

## 2026-10-10: 初期導入

- 公式CLI `bunx mygo-cli init -name ParalinGo -module paralingo app` でWebテンプレート生成。
- CLI / runtime: 0.3.7（初期テンプレート指定）。正確な解決版はbun.lock/go.sum参照。
- 既存環境のGoは1.25.7。生成されたgo.modは1.27.1を要求し、自動取得が発生。
- 作業ディレクトリが `.git` を含むと、CLIは空ディレクトリではないとして拒否。`app/` に生成。
- GoサービスからTypeScriptバインディングを生成し、ライブラリ保存を呼び出す設計。
