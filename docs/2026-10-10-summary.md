# 開発サマリ — 2026-10-10

## 目的と決定事項

英語リーディングを支援するデスクトップブラウザ「ParalinGo」を開発する。個人開発の再開とMyGOの評価も目的。英文と日本語訳を交互に読み、記事・表現を保存して読み返し、将来は保存内容から復習教材を生成する。

- MyGOを使用する。Goバックエンド + TypeScript/ViteのWeb UI。
- AIはChatGPTサブスク枠を使う公式Sign in with ChatGPT方式。
- 従量課金APIへの自動切り替えはしない。旧APIキー入力方式は削除済み。
- ChatGPT側の追加クレジット利用はアプリから強制できない。サブスク内に収めるにはChatGPT側のParalinGo利用設定が必要。

## 今日実装した機能

### 対訳リーダーと保存

- 英文一文と日本語訳を交互に表示。
- 訳は常時表示・クリック表示・非表示を切り替え可能。
- 文章の貼り付け、ライブラリ、表現メモ、読書位置の保存。
- 英文の選択から表現を登録。
- Markdown書き出し、JSONバックアップ・読み込み。
- Go経由でOS設定フォルダの `ParalinGo/library.json` に保存。一時ファイルから置換。
- WebプレビューはlocalStorageを使用し、デスクトップ版とは保存先が異なる。

### Web閲覧・記事取り込み

- 「URLから読む」でMyGOの別ウィンドウに外部ページを表示。
- 戻る・進む・再読込。
- 表示中DOMからarticle/main内の段落を優先して取り込み。
- タイトル・現在URL・本文を編集画面へ送り、文ごとに分割して保存。
- 日本語訳が空でも保存可能。

### 翻訳・学習補助

- 学習目標（TOEIC目標点・英検級）に応じた解説を生成。
- 全文対訳、最大8件のチャンク・表現解説、英語サマリと日本語訳。
- 生成した表現を自分の表現メモへ保存。
- 生成結果を記事に保存し、Markdownにも書き出す。
- 記事全体を1回の生成リクエストで送信する。
- ストリーミングを受信するが、途中表示はせず完了後に一括表示・保存。
- 1回80文・24,000文字まで。自動分割は未実装。
- 生成中の経過秒数、完了、エラーを記事上部に表示。生成は120秒でタイムアウト。
- 文数不一致や原文に存在しない抽出表現などは結果を採用しない。

### ChatGPTプラン接続

- 「ChatGPT接続」→ Continue with ChatGPT → 公式システムブラウザで認証。
- ローカルコールバック、PKCE/state/nonce、OIDC署名・issuer・audience・期限を検証。
- 接続アカウントで利用可能なモデルを取得し、選択する。
- Responses APIを `store:false` / `stream:true` で使用。
- トークンはGoのメモリ内のみ。再起動後は再ログイン・モデル選択が必要。
- ホストIDとクライアント登録情報はOS設定フォルダの `ParalinGo/chatgpt-registration.json` に保存。
- ログアウト時に公式セッション失効を試み、未確認の場合はChatGPT設定からの解除を案内。

## 起動・検証

```sh
cd ~/dev/ParalinGo/app
bun install
bun run dev
```

```sh
bun run build:web
CGO_ENABLED=0 go test ./...
go test -race ./...
bunx mygo-cli vet .
```

主なファイル: `app/src/main.ts`（画面）、`app/src/style.css`（見た目）、`app/main.go`（起動・保存）、`app/browser.go`（外部閲覧・抽出）、`app/chatgpt.go`（認証・モデル）、`app/learning.go`（生成・結果検証）。MyGO評価は `docs/mygo-evaluation.md` に継続記録。
